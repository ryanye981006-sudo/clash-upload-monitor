口径说明

数据来自定时轮询 Clash /connections 并做差分采样（间隔 3 秒）。
归因覆盖率 <100% 表示部分上传来自区间内已关闭、来不及观测的连接（Clash 不保留关闭连接的明细）；
覆盖率 >100% 表示新建立的连接把其建立以来的累计上传一次性计入了当前区间。
采样时长越长，覆盖率越收敛。

本报告只有经过 Clash 的流量。Clash 在系统代理模式下仅能看到 「遵守系统代理」的程序；不遵守的程序（部分网盘、IM、P2P 客户端）会直连外网并绕过 Clash，其上传不会出现在这里。如需覆盖全部流量，请启用 Clash 的 TUN 模式。 可用 python monitor.py status 查看「网卡发送速率 vs Clash 统计速率」， 两者差距即为未被归因的部分。

进程名优先取 metadata.process；该字段为空时回退到 metadata.processPath 的文件名（Clash for Windows 常见情况）。
